## Проект интерфейса CLI

В качестве основы текстового интерфейса в файле sim_cli.py я закладываю одну главную команду run со следующим набором аргументов:

### Доступные флаги для команды run:
* --duration / -d (целое число) — Длительность симуляции в TTI (миллисекундах). По умолчанию будет 50000.
* --ue-count / -n (целое число) — Количество случайно генерируемых пользователей. По умолчанию 5.
* --scheduler / -s (строка) — Выбор алгоритма планировщика. Ограничим его двумя строгими вариантами, которые есть в коде: RoundRobin или ProportionalFair. По умолчанию будет RoundRobin.
* --qos (флаг-переключатель) — Если пользователь его указывает, то CLI переключает выполнение на функцию sim_with_manager_qos. Если флага нет, запускается стандартная sim_with_manager.

## Примеры работы интерфейса в консоли

### Сценарий 1: Просмотр встроенной справки
При вводе команды вызова помощи:

>  **Команда для терминала:**
> ```bash
> python3 sim_cli.py run --help
> ```

Программа сама выведет в терминал следующий текст:
```text
usage: sim_cli.py run [-h] [-d DURATION] [-n_UE_COUNT] [-s SCHEDULER] [--qos]

options:
  -h, --help            Показать это сообщение и выйти
  -d, --duration        Длительность симуляции в TTI (мс) [дефолт: 50000]
  -n, --ue-count        Количество пользователей (UE) [дефолт: 5]
  -s, --scheduler       Алгоритм планировщика (RoundRobin / ProportionalFair)
  --qos                 Запустить симуляцию в режиме QoS-трафика
```

### Сценарий 2: Запуск симуляции с кастомными параметрами
Если ввести команду запуска со своими флагами:

>  **Команда для терминала:**
> ```bash
> python3 sim_cli.py run --duration 5000 --scheduler ProportionalFair --ue-count 3
> ```
