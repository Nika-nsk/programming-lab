# ОТЧЕТ О ПРОДЕЛАННОЙ РАБОТЕ №1

## Тема: Разработка интерактивного пользовательского интерфейса управления и визуализации системного симулятора мобильной сети (Frontend)

**Исполнитель:** Студент 2 курса Бойченко Вероника Алексеевна
**Репозиторий:** `ui-system`  
**Технологический стек:** React 18+, Vite 7, Tailwind CSS 4, Axios, REST API  

---

## 1. Цели и задачи этапа
В соответствии с утвержденным планом практики, на первом этапе были поставлены следующие задачи:
* **Локальное развертывание:** Перенос проекта из удаленного репозитория на локальный компьютер, настройка окружения и запуск сервера.
* **Архитектурный аудит:** Изучение структуры папок React-приложения, зон ответственности модулей и логики страниц.
* **Анализ интерфейсных сценариев:** Исследование компонентов вывода графиков, ресурсной сетки (Resource Grid) и модулей сохранения настроек.
* **Аудит сетевого взаимодействия:** Оценка текущего состояния обмена данными с сервером (REST API).
* **Составление перечня функций:** Классификация элементов проекта по степени готовности (работающие, частично работающие, заглушки).

## 2. Выполненная работа

### 2.1. Развертывание окружения
Проект был успешно клонирован и развернут в среде WSL (Ubuntu) с использованием пакетного менеджера NPM. В ходе развертывания были устранены конфликты версий сборщика Vite 7, требовавшего Node.js версии не ниже v20.19+. Локальный сервер разработчика запущен без ошибок.

### 2.2. Структура исходного кода (`src/`)
В результате анализа кодовой базы была изучена структура папок и определено назначение ключевых файлов:

```text
src
├── App.jsx                  # Корневой маршрутизатор (клиентский роутинг)
├── main.jsx                 # Точка инициализации React-приложения
├── api/                     # Сетевой уровень (REST API)
│   ├── axios.js             # Экземпляр Axios с базовыми настройками
│   └── simulation.js        # Запросы управления симуляцией (заглушки + REST)
├── components/              # Переиспользуемые UI-блоки
│   └── graphs/              # Компоненты графиков (BoxPlot, LTEGrid)
├── contexts/                # Управление глобальным состоянием
│   └── SettingsContext.jsx  # Хранилище параметров текущей сессии
├── locales/                 # Словари локализации (RU / EN)
└── pages/                   # Экраны пользовательского интерфейса
    ├── Home.jsx             # Главная страница
    ├── Settings.jsx         # Панель конфигурации параметров сети
    └── Visualization.jsx    # Панель интерактивных графиков
```

## 4. Выявленные архитектурные дефекты и баги

* **Ошибка логики локализации в `Visualization.jsx`**  
  Запись дефолтных настроек трафика привязана к языку интерфейса: `[t("settings.traffic.poisson")]: { packet_rate: 1 }`. При смене языка с русского на английский ключи перестанут совпадать, и приложение потеряет текущие настройки. Требуется рефакторинг на статические ключи.

* **Жестко прописанные параметры сети в `Settings.jsx`**  
  Параметры `bs_coords` (координаты базовой станции) и `bs_bw_mhz` (ширина полосы частот 10 МГц) вшиты в код. Пользователь лишен возможности настраивать эти данные. Необходимо вывести данные параметры в пользовательский интерфейс.
